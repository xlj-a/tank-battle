# 坦克大战 · Tank Battle

一个使用纯 HTML5 Canvas 编写的经典坦克大战游戏，无需任何依赖，直接在浏览器中运行。

## 玩法

- 控制己方坦克，消灭所有敌方坦克，同时保护底部的基地（金色徽章）。
- 基地被摧毁或生命耗尽则游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `Enter` | 开始 / 重新开始 |

移动端支持触屏虚拟按键。

## 元素

- 🧱 砖墙 — 可被子弹摧毁
- ⬜ 钢墙 — 无法被摧毁
- 🌊 水 — 坦克无法通过，子弹可以穿过
- 🌳 草丛 — 坦克与子弹均可通过，但会遮挡坦克
- 🛡️ 基地 — 被摧毁则游戏结束

## 道具

- ⭐ 升级 — 提升子弹速度与射速
- 💣 炸弹 — 消灭场上所有敌人
- ❤️ 生命 — 增加一条命
- 🔺 护盾 — 短暂无敌

## 运行

直接用浏览器打开 `index.html`，或部署到 GitHub Pages。
